# 检查奇数编号位

位编号从最低位的 0 开始。补全 `allOddBits`：当 `x` 的所有奇数编号位都是 `1` 时返回 `1`，否则返回 `0`。

```c
allOddBits(0xAAAAAAAA) == 1
allOddBits(0xFFFFFFFD) == 0
```

## 学习范围

- 位编号与掩码
- 按位与和按位异或
- 由小常量构造重复位模式

## 代码要求

- 合法操作符：`!`、`~`、`&`、`^`、`|`、`+`、`<<`、`>>`
- 最多 12 个操作符
- 整数常量只能使用 `0` 到 `255`
- 只补全函数体；题目不会自动检查操作符限制
