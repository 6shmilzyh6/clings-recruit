# 用位运算实现条件选择

补全 `conditional`，使其行为与 C 表达式 `x ? y : z` 相同：`x` 非零时返回 `y`，否则返回 `z`。

```c
conditional(2, 4, 5) == 4
conditional(0, 4, 5) == 5
```

## 学习范围

- 逻辑值归一化
- 全 0 / 全 1 掩码
- 按位与、或组合选择结果

## 代码要求

- 合法操作符：`!`、`~`、`&`、`^`、`|`、`<<`、`>>`
- 最多 16 个操作符
- 整数常量只能使用 `0` 到 `255`
- 只补全函数体；题目不会自动检查操作符限制
