# 判断 ASCII 数字字符

补全 `isAsciiDigit`：当 `x` 的值位于 `0x30` 到 `0x39`（含边界）时返回 `1`，否则返回 `0`。

```c
isAsciiDigit(0x35) == 1
isAsciiDigit(0x3A) == 0
isAsciiDigit(0x05) == 0
```
