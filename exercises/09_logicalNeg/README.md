# 不使用逻辑非判断零

补全 `logicalNeg`，实现与 C 语言逻辑非运算符 `!x` 相同的行为，但函数体中不能使用 `!`。

```c
logicalNeg(3) == 0
logicalNeg(0) == 1
```

- 负数的符号位
- `x` 与 `-x` 的关系
